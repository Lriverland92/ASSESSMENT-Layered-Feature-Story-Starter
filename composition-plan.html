Project: New Jersey: From Colonial Times to Today

I used CSS Grid to organize my article and kept the content in a normal reading order. I used positioning for the badge, navigation, header decoration, and pull quote. I also included fallback styles so the content stays readable if some CSS properties are not supported.

Layout and Positioning Decisions

Element Purpose Normal-flow baseline Technique Containing block / layer Fallback Required test
Issue badge Identifies the feature. Appears after the introduction. Absolute positioning. The header is positioned relative and creates an isolated stacking context. The badge returns to normal flow on smaller screens. Check at 320px, 768px, and 1280px to make sure nothing overlaps.
Story navigation Helps readers move between sections. Appears before the article. Sticky positioning on wider screens. The main Grid container limits the sticky navigation. Normal positioning on smaller screens. Check scrolling, keyboard navigation, and links.
Pull quote Highlights an important part of New Jersey's history. Appears between paragraphs. Relative positioning with a negative horizontal margin. Uses the raised layer. Negative margins are removed on smaller screens. Check overlapping and 200% zoom.
Header decoration Adds a decorative shape. The header works without it. Absolute pseudo-element with a rounded corner. Positioned inside the header with pointer-events disabled. The header remains readable without the decoration. Check that links and focus are not blocked.
Article sections Separate the different historical periods. Follow the normal reading order. Rounded borders. No extra stacking context. Square corners would not affect the content. Test longer content and smaller screens.
Feature illustration Adds a visual element to the introduction. Figure and caption stay in normal flow. Polygon clip-path. Only the image is clipped. The image keeps its rounded rectangular shape. Disable clip-path and check that the image remains visible.
Industrial illustration Allows text to wrap around the image. Image appears before the paragraphs. Float, shape-outside, and shape-margin. The section contains the float using flow-root. Normal float wrapping on wider screens if shapes are unsupported. Centered image on smaller screens. Disable shape-outside and check text readability.

Layer Scale

I used four z-index values to organize the layers: base (0), raised (1), sticky (2), and overlay (3). The pull quote uses the raised layer, the navigation uses the sticky layer, and the badge uses the overlay layer. The header also has its own stacking context to keep its decoration behind the text.

Responsive Design

When the screen is smaller than 52rem, the layout changes to one column. The badge and navigation return to normal positioning, the pull quote no longer uses negative margins, and the illustration is centered instead of floated.

Browser Support and Fallback Record

Documentation prepared November 16, 2026. I used the MDN documentation to identify browser support and fallback options for the CSS properties in this project. The tests I completed were done in Google Chrome.

  • MDN: position — Sticky positioning is widely supported in modern browsers. On smaller screens, the navigation returns to normal flow.
  • MDN: z-index — I used z-index values to control which elements appear in front of others.
  • MDN: border-radius — Rounded corners are decorative, so the content would still work without them.
  • MDN: clip-path — I used clip-path to create a decorative shape on the main illustration. When I disabled it in Chrome DevTools, the image remained visible.
  • MDN: shape-outside — I used this property to wrap text around the industrial illustration. If it is not supported, the text can still wrap around the regular rectangular float.
  • MDN: shape-margin — This property adds space between the image shape and the text. Regular margins provide spacing if it is not supported.

Testing Notes

I tested the website at different screen sizes using Chrome DevTools. I also tested keyboard navigation with the Tab key and checked the sticky navigation while scrolling.

For the content growth test, I repeated the main title and duplicated a paragraph. Both adjusted without being cut off or overlapping. I restored the original content afterward.

I also tested the clip-path fallback. When I disabled the property, the image remained visible without its decorative shape. The shape-outside fallback and 200% zoom results still need final confirmation.

The HTML validator reported a warning about the article element not having its own heading. The CSS validator reported three errors involving shape-outside and shape-margin. I kept these properties because they are required for the assignment.
